# fx: hit/heal effect engine (T28b)

Source art and rules: `design/fx/README.md`, SPEC rule 4. Not wired into the play screen yet (T28c).

| Piece | What it is |
|---|---|
| `Fx` (generated by `:app:generateFx`) | One enum entry per `design/fx/<name>/` with a `meta.txt` (top level only). `Fx.byName("pow")`, `frameCount` (last frame is empty), `holdMs(i)`, `ink(i)` / `knockout(i)` layers, `width`/`height`, `anchorRef/Dx/Dy`, `role`. |
| `FxPolicy` | `choose(netDelta, ko)` returns `Fx?`. Damage → `pow`, heal → `twinkle`, 0 → null. `policy[Trigger.BIG_HIT] = Fx.byName("wham")` and similar entries map more effects. |
| `FxPlayer` | Pure per-seat playback: `play`, `cancel`, `cancelAll`, `current(seat)`, `frame(seat)`, `enabled`, `holdScale`, `maxConcurrent` (2). |
| `FxRenderer` | Draws one frame: knock-out layer as paper, then black layer as ink, using blit rotation. `draw`, `drawCurrent`, `prewarm`. |
| `FxLayout` | Pure placement maths: `place` (frame footprint from the ink box and rotation) and `textInkBox`. |

## Wiring it into PlayView (T28c)

1. **Construct** (once per View):
   ```kotlin
   val fxScheduler = HandlerScheduler(handler, PlayLayout.PLAYERS)   // its own: timer ids = seats
   val fx = FxPlayer(PlayLayout.PLAYERS, fxScheduler) { seat -> invalidateFx(seat) }
   fxScheduler.target = fx
   val fxDraw = FxRenderer(r)
   val fxPolicy = FxPolicy()
   ```
   Do not share `PendingDeltas`' scheduler, because its timer ids are also seat indices.
   `fx.enabled` is the settings switch. Setting it to false cancels everything. `fx.holdScale` is the
   on-device tuning knob.
2. **Prewarm** in `onSizeChanged`, next to `prewarmGlyphs`, while `r.begin(scratch)` is active:
   `fxDraw.prewarm()`. This builds every layer's scaled mask once, so `onDraw` never builds one.
3. **Trigger**: call this once per committed delta group, never per tap. `PendingDeltas.commit`
   zeroes `delta` *before* it calls `Sink.onGroupCommitted`. Either pass the net delta through the
   sink (`onGroupCommitted(seat, net)`) or read `pending.delta(seat)` before committing. Then:
   ```kotlin
   fxPolicy.choose(net, ko = newLife <= 0)?.let { fx.play(seat, it) }   // false = dropped: draw clean
   ```
   Hold-to-repeat never calls this. Only the commit does. Commander damage linked to life uses the same
   net life change. Poison and counters get no effect.
4. **Cancel**:
   - Any touch-down on a seat's zones calls `fx.cancel(seat)` *before* the life change is applied.
     That is a tap or the start of a hold.
   - Undo, reset, new game, a layout or size change, and `onDetachedFromWindow` call `fx.cancelAll()`.
   - Also call `fxScheduler.cancelAll()` on detach.
5. **Invalidate** in `onFrameChanged(seat)`: invalidate only the effect footprint. Keep one
   preallocated `IRect` per seat, filled by `FxLayout.place(fx, inkBox, rotation, rect)` when `play`
   returns true. The listener also fires on the clean step, when `current(seat)` is already null, so
   the stored rect is what you invalidate then. The footprint overlaps the number, so `onDraw`
   redraws the number under it in the same pass. Clip the rect to the seat panel.
6. **Draw** in `drawSeat`, right **after** the life number and before any press-feedback
   `invertRect`:
   ```kotlin
   FxLayout.textInkBox(fp, rot, font.capTop * k, font.capHeight * k, inkBox)   // fp/k from numberFootprint
   fxDraw.drawCurrent(fx, s, inkBox, rot)
   ```
   - The knock-out layer must land on top of the freshly drawn number, so the order is: panel fill,
     number, effect.
   - Effects can extend past the ink box. If one could cross the panel edge (check `place` against
     `l.panels[s]`), wrap the draw in `canvas.save(); canvas.clipRect(panelDeviceRect)` …
     `restore()`. The clip is axis-aligned, so it is allowed. Never use `Canvas.rotate`.
   - Dark mode needs nothing: the layers follow `r.inverted`.

Anchors were designed against the `num-l` outline numerals. T28c re-fits them to the sticker
numerals by editing `design/fx/<name>/meta.txt` (`anchor`). The build regenerates everything.

## meta.txt as parsed

- `#` starts a comment, including trailing comments.
- Required keys: `size W H`, `frames N` (≥ 2), `anchor <ref> dx dy` (or `anchor dx dy` for
  centre), and `hold_ms h1 … hN`. The last hold is 0 and every other hold is > 0.
- Optional keys: `role damage|heal|big-hit|ko`, and `ink_px`/`knockout_px`/`flips` with N values each.
  The pixel counts are only checked loosely: a stale count prints a warning.
- When `role` is absent, the generator falls back to a built-in table for the T28a names. An
  unknown effect with no role fails the build.
- Frames must be exactly `frame-1.txt` … `frame-N.txt`, each H lines of W chars from `#o.`. The last
  frame must be empty.
- Any other key, a duplicate key, or a bad value fails the build with a `file:line` message.
