# fx: hit/heal effect engine (T28b, round-two support T28e)

Source art and rules: `design/fx/README.md` and, for round two, `design/fx/options/README.md`
(format) and `design/fx/options/render2.py` (the reference compositor); SPEC rule 4. Not wired into
the play screen yet (T28c).

| Piece | What it is |
|---|---|
| `Fx` (generated by `:app:generateFx`) | One enum entry per `design/fx/<name>/` with a `meta.txt` (top level only). Wraps an `FxSpec` (`fx.spec`) and forwards its accessors: `Fx.byName("pow")`, `frameCount` (last frame is empty), `holdMs(i)`, `ink(i)` / `knockout(i)` / `cut(i)` layers, `tiles` + `tileLayer(t, i)`, `width`/`height`, `anchorRef/Dx/Dy`, `role`. |
| `FxSpec` | Everything about one effect. Each frame is split by symbol into disjoint `FxLayer`s. |
| `FxOptions` (test-only, `:app:generateFxOptions`) | The same generator run over `design/fx/options/`, compiled into the unit tests only. The engine is tested on every round-two option without shipping any. |
| `FxPolicy` | `choose(netDelta, ko)` returns `Fx?`. Damage → `pow`, heal → `twinkle`, 0 → null. `policy[Trigger.BIG_HIT] = Fx.byName("wham")` and similar entries map more effects. |
| `FxPlayer` | Pure per-seat playback: `play`, `cancel`, `cancelAll`, `current(seat)`, `frame(seat)`, `enabled`, `holdScale`, `maxConcurrent` (2). |
| `FxRenderer` | Draws one frame: cut, tile layers, knock-out, ink (see "Draw order"). `draw`, `drawCurrent`, `drawAt`, `prewarm`, `cutUnderlay`. |
| `FxLayout` | Pure placement maths: `place` (the frame footprint from the ink box, plus the tile rect for `anchor tile`, and the rotation) and `textInkBox`. |

## Symbols and draw order

| Symbol | Layer | Drawn as |
|---|---|---|
| `x` | `cut(i)` | Invert under the mask (`DitherRenderer.drawMask(INVERT)`, blend DIFFERENCE): paper where the seat has ink, ink where it has paper. |
| `1`–`9` | `tileLayer(t, i)` | The tile named by `tile <d> <TILE> <mode>`, sampled at **global** screen phase: `ink` = ink where the tile has ink; `paper` = paper where the tile has ink; `fill` = the tile, opaque. |
| `o` | `knockout(i)` | `blit(invert = true)`: paper. |
| `#` | `ink(i)` | `blit`: ink. |

Every pixel holds one symbol, so the layers never overlap and the order cannot change the result. It
is fixed anyway (cut, tiles by ascending digit, knock-out, ink), and it equals `render2.py`'s
per-pixel `stamp` over the clean seat. `FxCompositeTest` checks this on every option, on both
seats, in both colour modes.

Rotation never touches the canvas. `#`/`o` use the blit's own rotation. `x` and tile layers are drawn
as the layer's turned view (`FxLayer.rotated`) on the untransformed canvas, so the mask turns and the
pattern phase stays global. Each turned view is one more scaled ALPHA_8 mask per rotation.

## Wiring it into PlayView (T28c)

1. **Construct** (once per View):
   ```kotlin
   val fxScheduler = HandlerScheduler(handler, PlayLayout.PLAYERS)   // its own: timer ids = seats
   val fx = FxPlayer(PlayLayout.PLAYERS, fxScheduler) { seat -> invalidateFx(seat) }
   fxScheduler.target = fx
   val fxDraw = FxRenderer(r)
   val fxPolicy = FxPolicy()
   ```
   Do not share `PendingDeltas`' scheduler, because its timer ids are also seat indices.
   `fx.enabled` is the settings switch. Setting it to false cancels everything. `fx.holdScale` is the
   on-device tuning knob.
2. **Prewarm** in `onSizeChanged`, next to `prewarmGlyphs`, while `r.begin(scratch)` is active:
   `fxDraw.prewarm(rotations = <the layout's seat rotations>)`. The default is `0, 180`. This builds
   every layer's scaled mask once, plus one mask per rotation for `x` and tile layers, so `onDraw`
   never builds one.
   - **Memory:** a tile-scale mask is 233×175 × S² bytes, about 650 KB at S = 4. Prewarm only the
     effects the policy can actually pick (`prewarm(listOf(...))`), not `Fx.entries`, once
     tile-scale effects ship.
3. **Trigger**: call this once per committed delta group, never per tap. `PendingDeltas.commit`
   zeroes `delta` *before* it calls `Sink.onGroupCommitted`. Either pass the net delta through the
   sink (`onGroupCommitted(seat, net)`) or read `pending.delta(seat)` before committing. Then:
   ```kotlin
   fxPolicy.choose(net, ko = newLife <= 0)?.let { fx.play(seat, it) }   // false = dropped: draw clean
   ```
   Hold-to-repeat never calls this. Only the commit does. Commander damage linked to life uses the same
   net life change. Poison and counters get no effect.
   - `FxRole.WIN` (`winner`) has no `FxPolicy` trigger. Play it directly when one player is left.
4. **Cancel**:
   - Any touch-down on a seat's zones calls `fx.cancel(seat)` *before* the life change is applied.
     That is a tap or the start of a hold.
   - Undo, reset, new game, a layout or size change, and `onDetachedFromWindow` call `fx.cancelAll()`.
   - Also call `fxScheduler.cancelAll()` on detach.
5. **Invalidate** in `onFrameChanged(seat)`: invalidate only the effect footprint. Keep one
   preallocated `IRect` per seat, filled when `play` returns true by
   `FxLayout.place(fx, inkBox, tileRect, rotation, rect)`. Pass the seat's **tile rect** (its panel,
   in dither px, on screen) as well as the ink box.
   - For `anchor tile` effects (`fx.spec.isTileScale`), the footprint **is the tile**, so the
     invalidation rect is the whole seat panel. Every tile-scale frame is 233×175 with a blank 3 px
     margin, so it never touches the dividers.
   - The listener also fires on the clean step, when `current(seat)` is already null, so the stored
     rect is what you invalidate then.
   - The footprint overlaps the number, so `onDraw` redraws the number under it in the same pass.
     Clip the rect to the seat panel.
6. **Draw** in `drawSeat`, right **after** everything that sits under the effect (panel fill, shadow,
   life number) and before any press-feedback `invertRect`:
   ```kotlin
   FxLayout.textInkBox(fp, rot, font.capTop * k, font.capHeight * k, inkBox)   // fp/k from numberFootprint
   fxDraw.drawCurrent(fx, s, inkBox, tileRect, rot)                          // tileRect = the seat panel
   ```
   - `x` inverts what is **already on the canvas**, so the number (and its shadow and the panel
     texture) must be drawn first, in the same pass. The knock-out and tile-paper layers also need
     the number beneath. The order is: panel fill, number, effect.
   - The old `drawCurrent(fx, s, inkBox, rot)` still works for ink-box effects, but it throws for
     `anchor tile` ones. Use the tile-rect overload everywhere.
   - Effects can extend past the ink box. If one could cross the panel edge (check `place` against
     `l.panels[s]`), wrap the draw in `canvas.save(); canvas.clipRect(panelDeviceRect)` …
     `restore()`. The clip is axis-aligned, so it is allowed. Never use `Canvas.rotate`.
   - Dark mode needs nothing. The layers follow `r.inverted`, and an invert is its own dark mode.
   - **API < 29** (no blend DIFFERENCE, `DitherRenderer.canInvertInPlace` false): set
     `fxDraw.cutUnderlay` once to a `Runnable` that redraws everything under the effect (panel fill,
     shadow, number) for the seat being drawn. The renderer runs it with `inverted` flipped, inside a
     layer clipped to the cut mask. Without it, `x` layers are skipped on old devices, as
     `invertRect` is. The Nomad is API 29+.
7. **KO** (`ko-shatter`): the effect ends on the clean number. Draw the dead panel when it ends, as
   the options README says.

The anchors were designed against the sticker numerals and a 233×175 seat tile. With a panel of
another size, `anchor tile` centres on it (floor), so a 234-wide panel shifts the frame by at most 1 px.

## Adopting a round-two option (T28c)

Copy `design/fx/options/<name>/` up to `design/fx/<name>/`. The engine already supports `x`, tile
layers and `anchor tile`, and the generator knows each option's role, so no meta edit is needed (or
add a `role` line). Then map it in `FxPolicy`. `FxGeneratedTest` covers it automatically, and
`FxOptionsGeneratedTest` keeps covering what is left in `options/`.

## meta.txt as parsed

- `#` starts a comment, including trailing comments.
- Required keys: `size W H`, `frames N` (≥ 2), `anchor <ref> dx dy` (or `anchor dx dy` for
  centre), and `hold_ms h1 … hN`. The ref is `centre|tl|tr|bl|br|top|bottom|left|right` on the ink
  box, or `tile` on the seat tile. The last hold is 0 and every other hold is > 0.
- `tile <d> <TILE> <mode>`: one line per digit `1`–`9`. TILE is a name from `design/patterns/`, such
  as `D4`, `HLINES` or `CHECKER`, and the mode is `ink|paper|fill`. An unknown tile name, a bad
  mode, a repeated digit, or a frame digit with no `tile` line fails the build. A declared digit
  that no frame uses only warns.
- Optional keys: `role damage|heal|big-hit|ko|win`, and `ink_px`/`knockout_px`/`cut_px`/`tile_px`/
  `flips` with N values each. The pixel counts are only checked loosely: a stale count prints a
  warning.
- When `role` is absent, the generator falls back to a built-in table for the T28a and T28d names.
  An unknown effect with no role fails the build.
- Frames must be exactly `frame-1.txt` … `frame-N.txt`, each H lines of W chars from `.#ox1-9`. The
  last frame must be empty.
- Any other key, a duplicate key, or a bad value fails the build with a `file:line` message.
- Generated data: each layer is a run-length code in string constants (`FxLayer.rle`), decoded once
  at class init. This keeps every class initialiser tiny and puts the bytes in the constant pool.
  All 23 effects (shipped + options) generate 53 KB of source and 91 KB of class files, with the
  largest class at 12 KB.
